完整使用说明

  1. 拍清完整动作

    固定机位，保留篮球、双手和双脚。优先使用原速视频，一段保留一次完整投篮。

  2. 先看一个重点

    正式产品给出主要观察、对应片段和下一球提示。没有明确问题时，可以保留原动作。

  3. 逐段核对画面

    在每项讲解旁回看对应片段，使用慢放和逐帧操作；同时查看解释、补充发现和分析限制。

  4. 再拍一次验证

    尝试一个提示，再拍同机位、同距离的一球，结合自己的手感回看。多球自动汇总暂未开放。

关于 P-SHOT

让建议有画面可查。

P-SHOT 是仍在迭代中的个人篮球训练项目。它把视频中的动作观察、相关解释和练习建议分开呈现，让使用者能核对建议来自哪段画面。

已接入的单球观察包括动作先后、球或手与腿的配合、下蹲回升、最低点球位、腿臂衔接、出手手臂、出手与身体上升、上身姿态变化。各项取决于拍摄机位和可见程度。

不把球星数值当作统一标准，不从普通视频直接判断肌肉发力、指尖力量或真实三维重心，也不承诺命中率提升。

常见问题

这是开源项目吗？

目前采用“公开展示、核心私有”的方式。展示站可以公开访问，核心分析程序和模型不在公开仓库中。公开可见不代表授予开源许可证。

为什么现在不能上传视频？

真实分析需要运行模型的计算资源。当前先开放零 AI 调用费用的示意体验，线上分析服务还未部署，不提供虚假的上传或分析结果。

会消耗我的 DeepSeek 余额吗？

不会。本展示站没有 DeepSeek 请求，也不接收你的 API 密钥。未来如果开放 AI 教练，会另行说明使用方式和额度。

有用户人数限制吗？

展示站不设注册或人数门槛，但访问仍受托管平台的带宽和服务限制。这里不承诺无限并发或永久免费的视频推理。
