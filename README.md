# P-SHOT · 看这一球，练下一球

个人篮球训练项目：把单次投篮的动作观察、对应片段与下一球提示放在一起，让建议有画面可查。

**[打开公开展示站](https://yigongwugezi.github.io/p-shot/) · [阅读使用说明](GUIDE.md)**

**展示站中的动画是虚构动作示意，不是真实用户视频、算法输出、准确率验证或标准姿势。** 网站不设注册或人数门槛，仍受 GitHub Pages 的服务与流量限制。

## 产品关注什么

- 动作先后：准备、下蹲、起身、离手与身体上升的关系。
- 球或手与腿的配合：举球与身体动作如何衔接。
- 下蹲与回升：最低点及其前后的变化。
- 最低点球位：同一帧中球相对身体的位置。
- 腿臂衔接：起身段腿部与投篮臂的伸展关系。
- 出手手臂：离手附近的手臂状态。
- 出手与身体上升：离手相对骨盆画面最高点的位置。
- 上身姿态变化：最低点到离手的上身变化。

这些观察已在本地产品按条件接入；不会强制凑满八项。随挥与落地等已有观察由其他报告模块呈现。实际报告取决于拍摄方向、清晰度、遮挡、时间轴和篮球可见程度。

## 正式产品的阅读方式

先看主要观察和下一球提示，再在每项讲解旁回看对应片段。解释、补充发现与分析限制分别保留。播放器支持慢放、逐帧与关键阶段跳转。本地产品可复制摘要、导出含关键画面的 HTML 报告；导出图文不等于独立证据视频。

不使用球星角度作为统一标准，不承诺命中率提升。普通单机位视频不能直接测量肌肉发力、指尖力量或真实三维重心。

## 公开展示，核心私有

本仓库只发布项目介绍、使用说明和独立展示代码。核心分析后端、诊断规则实现、模型权重、密钥、研究数据和原始视频不随本仓库发布。

网页展示代码可在浏览器与本仓库查看。核心私有不等于网页代码不可见。本项目目前未按开源许可证发布核心程序。

## 费用与数据

本站没有视频上传接口、登录系统或付费 AI 请求，不需要用户提供 API 密钥，也不读取本机视频。不添加第三方统计或外部字体；GitHub 作为托管方仍可能记录访问日志。后续开放真实分析前，会另行说明数据保存、删除方式、算力和 AI 使用额度。

## 运行这个展示站

```bash
python -m http.server 4173
```

打开 `http://localhost:4173`。无需模型、后端或 API 密钥。GitHub Pages 使用本仓库 `main` 分支根目录发布。
